# Arn0 Live TV / Hidden Apps fork

This is a complete source archive based on the Arn0 TV project:

- Upstream project: https://github.com/NelsonEU/arn0-tv
- Original project license: see `LICENSE`
- Fork-specific changes: `docs/FORK-CHANGES-LIVE-TV.md`
- Arch Linux build/install steps: `INSTALLATION-ARCH.md`
- TV installation/signing utility: https://github.com/Apps2Samsung/Apps2Samsung

The archive contains the source tree and original assets. Installing or building this fork does not clone another repository. Apps2Samsung is not bundled; it is an external tool used to sign and install the locally built `dist/arn0-launcher.wgt`.
